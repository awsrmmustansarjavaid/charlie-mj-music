# Integrations

## YouTube

Uses YouTube Data API v3 search. Configure `YOUTUBE_API_KEY`.

## Spotify

Uses Spotify Web API client credentials to obtain an access token and search tracks. Configure client ID and secret.

## AudD

Receives a recorded audio sample and sends it to AudD. Configure `AUDD_API_TOKEN`.

## Ollama

Calls the local Ollama HTTP API. Configure `OLLAMA_URL` and `OLLAMA_MODEL`.

Provider availability can change. Check each provider's current documentation and terms before deployment.
