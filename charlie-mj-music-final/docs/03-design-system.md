# Romantic Design System

## Visual direction

The interface uses midnight, wine, plum, rose and soft cream tones. Large blurred light fields create depth. Tiny hearts and sparkles move slowly behind the content.

## Shape language

Primary actions use rounded heart/pill forms. Content cards use large rounded corners and glass surfaces. Labels are small, letter-spaced and rose colored.

## Responsive behavior

Bootstrap's grid handles layout changes while custom CSS adjusts typography, spacing, cards and hero composition for narrow screens.

## Accessibility

Controls retain text labels. Motion can be reduced with `prefers-reduced-motion`. Images receive alt text and provider links open in a new tab with `noopener`.
