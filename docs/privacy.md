# Privacy

Charlie MJ Music has no Charlie MJ Music backend.

## Local information

The following can remain in the browser:

- moment details
- personal story
- partner nickname
- selected photo
- saved memories
- theme preference

## External searches

When a user chooses a search, the generated query is sent to the selected external search service because the browser is navigating to that service.

Users should avoid putting highly sensitive personal information into a public search query.

## Credentials

The repository contains no private production API keys.
