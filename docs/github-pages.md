# GitHub Pages Deployment

## Manual deployment

This project does not require GitHub Actions.

1. Push the repository to GitHub.
2. Open repository **Settings**.
3. Open **Pages**.
4. Choose **Deploy from a branch**.
5. Choose `main`.
6. Choose `/ (root)`.
7. Save.

GitHub will publish the static files.

## Important

Do not add private API keys to `js/app.js`, HTML, CSS, JSON, or any other tracked file.
